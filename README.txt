The Range 圣诞树与树裙独立报告

所有常规采集已改为自有云端程序，Firecrawl 调用入口禁用，工作流不再接收 FIRECRAWL_API_KEY。

目录通过官网公开接口读取，普通HTTP受限时使用正常Chromium浏览器读取同一公开接口。完整分页、唯一SKU、在库状态及广告排除规则保持不变。六个界面是同一份目录的筛选视图。

商品详情、具体SKU选择与新品原站截图均由自有浏览器处理，不调用Firecrawl。每期定期刷新默认核验全部SKU，保留每款真实核验时间；新款邮件继续每周三北京时间07:00检查、确认订阅后发送。

GitHub公开仓库的标准ubuntu-latest运行器执行采集。浏览器会消耗计算时间和网络流量，Firecrawl积分消耗为0；不使用大型付费运行器或外部付费代理。定时任务可能有云端排队延迟。

daily-pages.yml为唯一采集和发布入口；旧schedule-monitor.yml仅为手动兼容入口，没有重复定时器。全量周期仍可选择3/5/7天及北京时间时分，默认7天00:00。推送和退订的私密Cloudflare/Brevo后台不变。

软件检查确保付费采集函数不能调用、官网故障不会触发付费回退、不同零售商SKU缓存隔离。只有线上真实采集成功后才可声称首轮新通道已验证；probe模式会读取完整类目、一个具体SKU规格并生成截图。

以后新增零售商和品类时，新增相应公开数据源适配器，复用采集、校验、缓存和发布框架。不同零售商使用独立retailerId，不混淆同号SKU。当前已实现的来源为The Range，不声称未知零售商已经接入。
