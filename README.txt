The Range 圣诞树与树裙独立报告

Firecrawl 节省模式（2026-11-01）
目录和普通商品系列通过按运行时间计费的代码浏览器会话批量读取。官网同系列JSON包含独立SKU、商品ID、颜色、尺寸和规格，按具体SKU核对后复用一次读取结果。六个页面共用同一份发布数据，浏览、筛选和图表切换不消耗采集积分。
已确认需要增强通道的商品系列合并检查，每批最多100个系列。一般异常地址只在本轮补抓一次；失败结果同系列共享，不按SKU反复付费。官网的循环跳转不会通过重试变成有效规格，异常字段明确列为未知，继续保留该商品当轮目录中的价格、库存和NEW证据。

图片质量
已保存的图片每批最多400个地址重新读取并比较源站指纹；新增或变化的文件每批最多200项取得真实媒体，不逐张调用scrape。未变化的照片不重复传回文件内容。请求开启真实媒体加载；HTTP 200、图片MIME和成功解码均不足以单独证明是商品照片。另检查像素尺寸，拦截1×1占位文件，计算SHA-256并保存未经生成或修饰的原始图片文件。网站展示经验证的本站副本。
正常全量更新仍会对全部图片重新请求或用源站ETag/Last-Modified条件核验；只有定向修复才保留已有证据时间，并只读取未通过的图片。源站图片地址、文件指纹和核验时间均保留。目录结束前再次全量核对，价格、库存、NEW和六类分析统一重算。
不调用付费AI浏览器提示、AI JSON抽取、OCR、Agent或Search来逐商品处理。真实新品截图继续按具体SKU核验，已有NEW基线不批量补发邮件。

积分保护
每轮最多60积分；按时计费会话上界20积分，其余增强批次与单地址补抓共用至多40积分。本项目每个北京时间自然月最多1000积分，账户另保留5000积分。
开始前读取实际余额，将本轮预留写入GitHub，然后启动付费工作。任务异常时预留仍存在，不因缓存丢失重置限额。浏览器数据工作结束立即关闭，再进行图片批次，避免空转计费。用Firecrawl账单结算；未获得完整账单时标为保守上界。
手动、自动、探测和修复使用同一串行入口。无到期工作时不启动付费采集；HTTP401/403及持续暂时故障有停止规则。单款坏链接不会触发整批付费重跑。

时间与范围
全量更新周期可选3/5/7天及北京时间时分；NEW每天北京时间07:00。邮件订阅、基线排除、具体SKU截图及发送去重保持原有规则。
该版本当前实现The Range。后续零售商需要各自的官网适配器，可复用预算、SKU命名空间、按批读取、图片指纹、失败去重及发布审计机制。
真实采集日期、详情覆盖、图片结果及费用以web/catalogue.json、web/status.json、web/collection-ledger.json为准，部署成功与采集质量分别记录。
