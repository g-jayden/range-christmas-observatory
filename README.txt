The Range 圣诞树与树裙独立报告

Firecrawl节省模式（2026-11-01）
主通道改为Firecrawl代码浏览器会话，按实际会话时间计费；不逐SKU调用scrape，不使用收费的AI浏览器提示、JSON抽取、OCR、Agent或Search。
同款多规格共享官网自身product.js读取的?json端点，并按sku、code、prod_id及商品路径核对。Colour映射遵循官网_swatch字段；尺寸不借用同系列其他规格。商品介绍及图片映射来自同一商品页面。
全量更新仍重新读取全部7类目录、全部对应SKU规格和主图片；六个界面只共用同一份发布数据，不进行6次重复采集。结束前再核对完整目录，按最新价格、库存和NEW重算统计。
图片按唯一URL批量实际加载与解码，不为每张图片支付scrape积分。新品邮件只对订阅后首次发现的NEW生成真实具体SKU商品页截图；不重复向已有新品发送邮件。

积分保护
每轮最多60积分；本项目每个北京时间自然月最多1000积分；保留账户5000积分供其他品类或项目使用。
开始会话前查询实际余额，将本轮积分预留提交到GitHub，再创建有服务端TTL硬上限的会话。任务异常结束时预留仍保留，不因缓存丢失重置预算。结束立即关闭会话，使用Firecrawl返回的creditsBilled结算实际账单。无法取得账单时按已预留的会话上界计入，不虚报0。
所有自动或手动采集共用同一串行入口。HTTP401/403立即停止；临时故障最多两轮后停止，不无限重试。无工作时的定时检查不创建付费会话。

范围与验证
全量周期可选择3/5/7天和北京时间时分；NEW每周三北京时间07:00。推送与退订后台保留。
目录分页、唯一SKU、在库状态、广告排除、跨类目一致性及树裙独立分母保持校验。没有可核实的字段保留未知，不从名称推测尺寸或借用其他SKU。
首次云端完整实测结果以web/status.json及collection-ledger.json为准，部署成功不等于采集成功。
